PS4 Offline Host — Ultimate Custom Edition
===============================================

حقوق: © 2026 آدم بـوعـويـنـه

المميزات:
- واجهة موحدة.
- Boot screen وشريط تجهيز Cache.
- Service Worker وCache versioning.
- Cache Manager.
- Firmware selection (manual).
- Firmware paths الموجودة في المشروع.
- System Log.
- Settings / Sound / TV Mode.
- About وحقوق.

تشغيل Offline:
1) لا تفتح index.html عبر file:// إذا أردت Service Worker.
2) شغّل المشروع من HTTP/HTTPS محلي، مثل أي static web server.
3) افتح الموقع مرة مع الملفات متاحة ليتم تخزينها.
4) بعد اكتمال الكاش يمكن استخدام الملفات التي تم تخزينها بدون إنترنت.

ملاحظة:
متصفح PS4 لا يوفر لصفحة ويب عادية API موثوقاً لقراءة رقم System Software، لذلك زر "فحص الإصدار" لا يختلق نتيجة؛ الاختيار اليدوي هو البديل الآمن.
ملفات الاستغلال/payload الأصلية لم يتم تعديل منطقها بواسطة هذه الواجهة.
